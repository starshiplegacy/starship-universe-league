# CAL/CUL — Create A Lyrie / Crear Un Lyrie

Módulo de creación y personalización del personaje/Lyrie para **The LyrieLife**.

Esta carpeta está dentro de los recursos de The LyrieLife porque CAL/CUL forma parte del flujo del juego, pero se mantiene como módulo independiente para facilitar su reutilización en otros proyectos.

## Organización

- `characters/` — personajes y archivos de referencia del creador.
- `models/` — modelos 3D y recursos geométricos.
- `textures/` — texturas y materiales.

Coloca aquí únicamente recursos pertenecientes al creador CAL/CUL. No mezcles los modelos de League Of Legacy.
