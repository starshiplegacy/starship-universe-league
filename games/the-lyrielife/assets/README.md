Add the downloaded GLB exports to this folder with these exact filenames:

- `lyrie-character.glb` — the generated Lyrie character.
- `starter-home.glb` — the generated starter house.

The browser prototype requests these exact relative paths. If the files are absent, it uses procedural placeholder meshes so the scene can still load.
